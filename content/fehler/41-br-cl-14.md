detects: yes

**Kurz erklärt.** Jedes Land wird in der E-Rechnung als zweistelliger Code angegeben, zum Beispiel `DE` für Deutschland oder `AT` für Österreich. Steht dort ein Name, eine dreistellige Abkürzung oder ein erfundener Code, lehnt der Validator die Rechnung ab.

**Was die Regel genau prüft.** Im UBL-Format prüft die Regel jedes Element `cac:Country/cbc:IdentificationCode` in der Datei: beim Verkäufer, beim Käufer, beim Steuervertreter, bei der Lieferadresse und beim Herkunftsland eines Artikels. Der Wert muss genau einer der zweistelligen Codes der Liste ISO 3166-1 sein, in Großbuchstaben. Für Griechenland gilt hier `GR`, nicht `EL`.

## Typische Ursachen

- Im Kundenstamm steht das Land ausgeschrieben („Deutschland“, „Österreich“), und das Programm übernimmt den Text.
- Das Programm verwendet dreistellige Codes wie `DEU` oder Kfz-Kennzeichen wie `D` oder `A`.
- Ein Code in Kleinbuchstaben (`de`); die offizielle Liste enthält nur Großbuchstaben.
- Das Feld ist bei einem ausländischen Kunden mit einem Platzhalter wie `XX` gefüllt.

## So beheben Sie es

1. Prüfen Sie im Kundenstamm und in Ihren Firmendaten das Feld für das Land.
2. Tragen Sie den zweistelligen ISO-Code in Großbuchstaben ein: `DE`, `AT`, `CH`, `NL`, `FR`, `IT`, `ES`.
3. Kontrollieren Sie auch die Lieferadresse, falls Ihr Programm sie ausgibt.
4. Erzeugen Sie die Rechnung neu.

**Vorher (abgelehnt)**

```xml
<cac:PostalAddress>
  <cbc:StreetName>Am Deich 12</cbc:StreetName>
  <cbc:CityName>Husum</cbc:CityName>
  <cbc:PostalZone>25813</cbc:PostalZone>
  <cac:Country><cbc:IdentificationCode>Deutschland</cbc:IdentificationCode></cac:Country>
</cac:PostalAddress>
```

**Nachher**

```xml
<cac:PostalAddress>
  <cbc:StreetName>Am Deich 12</cbc:StreetName>
  <cbc:CityName>Husum</cbc:CityName>
  <cbc:PostalZone>25813</cbc:PostalZone>
  <cac:Country><cbc:IdentificationCode>DE</cbc:IdentificationCode></cac:Country>
</cac:PostalAddress>
```

**Häufig zusammen mit:** BR-09 und BR-11 (Ländercode von Verkäufer oder Käufer fehlt ganz) und BR-CO-09 (USt-IdNr. ohne Länderkürzel).

## Häufige Fragen

- *Welcher Code gilt für Griechenland?* In der Länderangabe `GR`. Das Kürzel `EL` ist nur am Anfang der griechischen USt-IdNr. üblich.
- *Und für Nordirland?* Die Liste der Regel enthält dafür den Code `XI`.

h1: BR-AE-10: Reverse Charge ohne Befreiungsgrund
meldung: [BR-AE-10]-A VAT breakdown (BG-23) with VAT Category code (BT-118) "Reverse charge" shall have a VAT exemption reason code (BT-121), meaning "Reverse charge" or the VAT exemption reason text (BT-120) "Reverse charge" (or the equivalent standard text in another language).
detects: yes

**Kurz erklärt.** Wenn Sie eine Rechnung mit Steuerschuldnerschaft des Leistungsempfängers (Reverse Charge, Kategorie „AE“) ausstellen, muss die Steueraufschlüsselung einen Befreiungsgrund enthalten: einen Code (BT-121) oder einen Text (BT-120). Der offizielle KoSIT-Validator (1.6.3, XRechnung 3.0.2) hat eine solche Rechnung ohne Begründung in unserem Test abgelehnt.

**Was die Regel genau prüft.** Jede Steueraufschlüsselung mit Kategorie `AE` braucht `cbc:TaxExemptionReasonCode` oder `cbc:TaxExemptionReason`. Ein Hinweis im Freitext der Rechnung (BT-22) zählt nicht.

## Typische Ursachen

- Im Kundenstamm ist kein Befreiungsgrund hinterlegt; das Programm schreibt Kategorie AE, aber keinen Grund.
- Der Hinweis „Steuerschuldnerschaft des Leistungsempfängers“ steht nur im PDF oder im Freitext.
- Bei Bauleistungen (§ 13b UStG) wird Reverse Charge von Hand gesetzt, ohne die passende Vorlage im Programm.

## So beheben Sie es

1. Hinterlegen Sie beim Kunden oder beim Artikel den Befreiungsgrund. Üblich ist der Code `VATEX-EU-AE`, dazu der Text „Steuerschuldnerschaft des Leistungsempfängers“.
2. Prüfen Sie, dass Ihre USt-IdNr. und die Ihres Kunden in der Rechnung stehen (sonst folgt BR-AE-02 oder BR-AE-03).
3. Erzeugen Sie die Rechnung neu.

**Vorher (abgelehnt)**

```xml
<cac:TaxCategory>
  <cbc:ID>AE</cbc:ID>
  <cbc:Percent>0</cbc:Percent>
  <cac:TaxScheme><cbc:ID>VAT</cbc:ID></cac:TaxScheme>
</cac:TaxCategory>
```

**Nachher**

```xml
<cac:TaxCategory>
  <cbc:ID>AE</cbc:ID>
  <cbc:Percent>0</cbc:Percent>
  <cbc:TaxExemptionReasonCode>VATEX-EU-AE</cbc:TaxExemptionReasonCode>
  <cbc:TaxExemptionReason>Steuerschuldnerschaft des Leistungsempfängers</cbc:TaxExemptionReason>
  <cac:TaxScheme><cbc:ID>VAT</cbc:ID></cac:TaxScheme>
</cac:TaxCategory>
```

**Häufig zusammen mit:** BR-AE-02 / BR-AE-03 (USt-IdNr. fehlt) und BR-AE-08 (Bemessungsgrundlage der Kategorie AE) und BR-AE-09 (Steuerbetrag muss 0 sein).

## Häufige Fragen

- *Reicht der Text allein?* Ja, die Regel verlangt Code **oder** Text. Mit beiden sind Sie auf der sicheren Seite.
- *Gilt Reverse Charge für meinen Umsatz?* Das klären Sie bitte mit Ihrer Steuerberatung.

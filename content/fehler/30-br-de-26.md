meldung: [BR-DE-26] Wenn im Element "Invoice type code" (BT-3) der Code 384 (Corrected invoice) übergeben wird, soll PRECEDING INVOICE REFERENCE BG-3 mind. einmal vorhanden sein.
detects: yes

**Kurz erklärt.** Diese Meldung ist eine **Warnung**, kein Fehler. Eine Korrekturrechnung soll sagen, welche Rechnung sie korrigiert. Fehlt dieser Verweis, weiß der Empfänger nicht, wozu die Korrektur gehört, und fragt nach oder lehnt ab.

**Was die Regel genau prüft.** Steht in `cbc:InvoiceTypeCode` der Code `384`, muss mindestens ein `cac:BillingReference/cac:InvoiceDocumentReference` vorhanden sein. Im XRechnung-Regelwerk ist die Regel als Warnung eingestuft („soll“, nicht „muss“).

## Typische Ursachen

- Die Korrektur wird als neue Rechnung mit Code `384` angelegt, ohne Bezug auf die alte Rechnung.
- Die Nummer der ursprünglichen Rechnung steht nur im Freitext (`cbc:Note`).
- Das Programm schreibt den Verweis in `cac:OrderReference` (Bestellung) statt in `cac:BillingReference`.

## So beheben Sie es

1. Notieren Sie die Nummer der Rechnung, die korrigiert wird, und möglichst ihr Datum.
2. Tragen Sie beides in `cac:BillingReference/cac:InvoiceDocumentReference` ein: Nummer in `cbc:ID` (BT-25), Datum in `cbc:IssueDate` (BT-26).
3. Erzeugen Sie die Korrekturrechnung neu.

**Vorher (Warnung)**

```xml
<cbc:InvoiceTypeCode>384</cbc:InvoiceTypeCode>
<cbc:Note>Korrektur zu Rechnung RE-2026-0142</cbc:Note>
```

**Nachher**

```xml
<cbc:InvoiceTypeCode>384</cbc:InvoiceTypeCode>
<cbc:Note>Korrektur zu Rechnung RE-2026-0142</cbc:Note>
…
<cac:BillingReference>
  <cac:InvoiceDocumentReference>
    <cbc:ID>RE-2026-0142</cbc:ID>
    <cbc:IssueDate>2026-10-15</cbc:IssueDate>
  </cac:InvoiceDocumentReference>
</cac:BillingReference>
```

Die Reihenfolge ist im UBL-Format fest: `cac:BillingReference` steht nach `cac:OrderReference` und vor den Vertragsangaben und Anhängen.

**Häufig zusammen mit:** BR-DE-17 (Rechnungsart nicht vorgesehen, als Warnung) und BR-55 (Verweis auf eine frühere Rechnung ohne deren Nummer).

## Häufige Fragen

- *Muss ich die Warnung beheben?* Die Rechnung scheitert an dieser Regel nicht. Viele Empfänger verbuchen eine Korrektur ohne Verweis aber nicht und schicken sie zurück.
- *Korrekturrechnung oder Gutschrift?* Für eine Gutschrift gibt es den Code `381`. Was in Ihrem Fall richtig ist, klären Sie bitte mit Ihrer Steuerberatung oder Ihrem Empfänger.

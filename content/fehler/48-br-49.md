h1: BR-49: Zahlungsangaben ohne Code der Zahlungsart
meldung: [BR-49]-A Payment instruction (BG-16) shall specify the Payment means type code (BT-81).
detects: yes

**Kurz erklärt.** Wenn eine E-Rechnung Zahlungsangaben enthält, muss sie auch sagen, wie bezahlt wird: per Überweisung, Lastschrift, Karte oder anders. Das geschieht mit einem Code. Fehlt der Code, lehnt der Validator die Rechnung ab, auch wenn die IBAN richtig dasteht.

**Was die Regel genau prüft.** Im UBL-Format muss jedes `cac:PaymentMeans` ein `cbc:PaymentMeansCode` enthalten. Gültig sind die Codes der Liste UNTDID 4461, zum Beispiel `58` (SEPA-Überweisung), `30` (Überweisung), `59` (SEPA-Lastschrift) und `48` (Karte). Dass der Code in dieser Liste steht, prüft eine eigene Regel, BR-CL-16.

## Typische Ursachen

- Das Programm schreibt die Bankverbindung, aber keine Zahlungsart.
- Die Zahlungsart steht nur als Text im Zahlungsziel („Zahlbar per Überweisung“), nicht als Code.
- Das Element `cbc:PaymentMeansCode` fehlt im Export ganz.

## So beheben Sie es

1. Stellen Sie im Programm die Zahlungsart ein, mit der Ihre Kunden zahlen sollen.
2. Bei Überweisung auf ein Konto im SEPA-Raum ist das meist `58`, außerhalb von SEPA `30`.
3. Prüfen Sie, dass `cbc:PaymentMeansCode` am Anfang von `cac:PaymentMeans` steht.
4. Erzeugen Sie die Rechnung neu.

**Vorher (abgelehnt):** Bankverbindung ohne Zahlungsart.

```xml
<cac:PaymentMeans>
  <cbc:PaymentID>RE-2026-0314</cbc:PaymentID>
  <cac:PayeeFinancialAccount>
    <cbc:ID>DE02120300000000202051</cbc:ID>
  </cac:PayeeFinancialAccount>
</cac:PaymentMeans>
```

**Nachher**

```xml
<cac:PaymentMeans>
  <cbc:PaymentMeansCode>58</cbc:PaymentMeansCode>
  <cbc:PaymentID>RE-2026-0314</cbc:PaymentID>
  <cac:PayeeFinancialAccount>
    <cbc:ID>DE02120300000000202051</cbc:ID>
  </cac:PayeeFinancialAccount>
</cac:PaymentMeans>
```

Die IBAN im Beispiel ist eine öffentlich verwendete Beispiel-IBAN, kein echtes Konto.

**Häufig zusammen mit:** BR-61 (Überweisung ohne Kontonummer), BR-DE-23-a (Überweisung ohne Kontoblock) und BR-DE-1 (Zahlungsangaben fehlen ganz).

## Häufige Fragen

- *Fehlen die Zahlungsangaben ganz, kommt dann BR-49?* Nein. BR-49 prüft nur vorhandene Zahlungsangaben. Bei einer XRechnung ohne Zahlungsangaben meldet sich BR-DE-1.
- *Darf der Code als Text stehen, etwa „Überweisung“?* Nein. Es muss ein Code der Liste sein, zum Beispiel `58`.
